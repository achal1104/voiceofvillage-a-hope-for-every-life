# VoiceOfVillage (GullyCrix theme)

    npm install
    npm run dev      # http://localhost:5173
    npm run build    # output in dist/

Uses HashRouter, so the built site works on any static host.
Theme: src/styles/style.css (tokens) + src/styles/enhance.css (GullyCrix overrides).

## Navbar
Defined in `src/data/nav.js` (3 dropdowns: Get Involved, Resources, Company) + "Register Your Village" link + "Support a Village" button.
All routed pages are real: Home, About, Explore Villages, Register, Support, Adopt, Volunteer, Emergency Needs, Ground Reality, Our Impact, NGO & CSR, Contact.
